# reallyme-crypto-jwk-multikey

JWK and Multikey public-key envelope conversion for ReallyMe Crypto.

Conversions use validated public-key encodings and assigned multicodec
identifiers. See the [JWK and Multikey contract](https://github.com/reallyme/crypto/blob/main/docs/jwk.md)
for supported algorithms and unavailable mappings.
